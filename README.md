#Bilingual Spam Detection Using XLM-RoBERTa

This repository contains the implementation and experimental work from my undergraduate thesis and research publication, “Advancing Web-Based Bilingual Spam Detection System with XLM-RoBERTa: Dataset Creation and Model Fine-Tuning.”

The project focuses on Bangla-English bilingual spam detection using XLM-RoBERTa. It includes the pretrained model implementation, the main bilingual spam detection model, and hyperparameter tuning experiments conducted during the research.

The work was presented at ICDSAIA 2025 and published in Springer CCIS.
